# OWASP Docker Top 10 #10 – Logging

## Overview

Logging is an essential security practice for monitoring containerized applications, detecting suspicious activities, troubleshooting failures, and supporting incident response. Docker captures everything an application writes to **stdout** and **stderr**, making logs easily accessible through the Docker CLI.

Proper logging enables administrators and security teams to monitor application behavior, investigate incidents, and maintain an audit trail of container activities.

---

## OWASP Recommendation

**Centralize, isolate, and aggregate container stdout/stderr streams to ensure reliable monitoring, auditing, and post-incident forensic analysis.**

## Application Source Code

### app.py

```python
import logging
import random
import time

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s"
)

while True:

    logging.info("Application Started Successfully")

    if random.randint(1,5)==3:
        logging.warning("High CPU Usage Detected")

    if random.randint(1,8)==5:
        logging.error("Database Connection Failed")

    time.sleep(5)
```

# Security Benefits of Logging

- Detect suspicious or malicious activities.
- Troubleshoot application failures quickly.
- Maintain an audit trail for compliance.
- Simplify incident response.
- Improve application monitoring and observability.
- Support forensic investigations after security incidents.

---

# Best Practices

- Write application logs to **stdout** and **stderr**.
- Avoid storing logs inside container filesystems.
- Configure log rotation to prevent excessive disk usage.
- Use centralized logging solutions such as:
  - ELK Stack (Elasticsearch, Logstash, Kibana)
  - Loki + Grafana
  - Splunk
  - Fluentd
- Monitor logs continuously for anomalies.
- Protect log integrity from unauthorized access or modification.

---

# Key Takeaways

- Docker automatically captures application logs from **stdout** and **stderr**.
- `docker logs` is useful for viewing historical logs.
- `docker logs -f` enables real-time log monitoring.
- `docker logs -t` provides timestamps for better auditing.
- Centralized logging is a recommended security practice for production environments.
