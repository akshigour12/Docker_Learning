# Docker SDK for Python

A simple CLI project demonstrating how to manage Docker using the Python Docker SDK.

## Features

- List containers
- Run containers
- Stop containers
- Start containers
- Restart containers
- Remove containers
- Show container logs
- Execute commands inside a container
- Inspect containers
- Display container statistics
- List images
- Pull images
- Remove images
- Build Docker images

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

## Requirements

- Python 3.10+
- Docker Desktop (or Docker Engine)
- Docker daemon running
